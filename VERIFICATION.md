# Проверка первой сборки

Дата: 3 октября 2026 года.

Проведено локально:

- 37 проверок Java: разбор цен и количества, копейки и граммы, округление, ограничения сумм, PIN-хеши, идентичность заказа и проверка банковских статусов.
- 6 тестов SQLite со схемой приложения: неизменность цен в старом заказе, уникальность запросов и банковских платежей, откат ошибочной замены, внешние ключи, фильтрация статистики и пагинация оплаченных заказов.
- Сборка основного APK и отдельного APK Android-тестов средствами официального Android SDK и JDK 21.
- Проверка APK-подписи; минимальная версия Android 8.0, целевая версия API 36. В манифесте требуется только разрешение на интернет.

Пока не подтверждено:

- Запуск и полный сценарий на настоящем Android-устройстве. Локальный эмулятор в этой среде не загрузился; Android-тесты собраны, но здесь не выполнены.
- Работа банковской страницы на выбранном устройстве, успешная операция тестового шлюза и реальное подтверждение оплаты Сбера. Банковских доступов нет.
- Выполнение GitHub Actions: результаты конкретного коммита доступны на вкладке Actions.

Для завершения проверки запустите Android-тесты из README на свежем эмуляторе, проверьте основные действия на телефоне / планшете и проведите банковский тест с выданным Сбером API-доступом. На этом этапе APK предназначен для проверки первой версии. Подключение физического терминала, фискализация, синхронизация устройств и автоматические возвраты в этой сборке отсутствуют.
