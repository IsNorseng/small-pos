# Малая касса

Приложение для Android 8.0+ для небольших кофеен, киосков и магазинов. Каталог, заказы и статистика хранятся в SQLite на одном устройстве. Лицензия MIT.

[Скачать тестовый APK](https://github.com/IsNorseng/small-pos/releases/tag/v1.0.0-preview.1) · [Руководство](docs/guide.md) · [Что проверено](VERIFICATION.md)

- **Покупатель** выбирает товары и оформляет заказ.
- **Продавец** проверяет ручную оплату, собирает заказ и отмечает выдачу. Для магазина можно отключить отдельную выдачу.
- **Администратор** меняет каталог и цены, смотрит продажи и сохраняет резервную копию.

При первом запуске задайте два разных PIN-кода, выберите шаблон каталога и попробуйте оформить заказ с ручным подтверждением оплаты.

СБП через Сбер настраивается отдельно. Реальный платёж ещё не проверен; физический терминал, фискальные чеки и синхронизация устройств в этой версии отсутствуют. APK предназначен для тестирования.

## Сборка

Нужны Python 3.10+, JDK 21 и Android SDK Platform / Build Tools 36+. Укажите пути в `JAVA_HOME` и `ANDROID_HOME`.

```sh
python scripts/build.py --core-test
python tests/sqlite_check.py
```

APK появится в `build/small-pos.apk`. Инструкции по подписи и Android-тестам есть в [руководстве](docs/guide.md).
